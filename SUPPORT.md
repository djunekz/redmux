# Support

For usage questions and troubleshooting:

1. Read the [README](README.md).
2. Review [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Run `redmux diagnose` and inspect `redmux logs`.
4. Search existing GitHub issues for the exact error.
5. Open a question/bug report with the requested diagnostic details.

When asking for help, include the REDMUX version, Android version, device architecture, Termux source, PRoot-Distro version, selected distribution, selected desktop, and the exact error output. Redact usernames, private paths, tokens, and other sensitive data.

Support is community-based and best-effort. REDMUX is not an official Termux or Linux distribution support channel.
